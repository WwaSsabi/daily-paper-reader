## 摘要
大型语言模型（LLMs）主要基于英语数据进行训练，编码了丰富的世界知识，但往往无法在其他语言中可靠地表达这些知识，这种现象称为跨语言事实不一致性。为了研究和解决这一问题，我们引入了PolyFact，一个大规模平行多语言事实问答数据集，包含12种类型多样的语言中的10万个基于Wikidata的事实。利用PolyFact，我们比较了轻量持续预训练（CPT）、监督微调（SFT）以及通过组相对策略优化（GRPO）的强化学习，以提升Qwen-2.5-7B和OLMo-2-1124-7B的跨语言事实回忆能力。我们发现GRPO始终优于SFT，既提升了跨语言一致性，也增强了对未见语言的泛化能力，而基于平行数据的CPT带来的额外收益有限。机制分析进一步表明，GRPO通过减少MLP层和注意力头中的语言专业化来重组多语言路由，从而促进更共享的跨语言表示。我们开源了代码、模型和数据集。

## Abstract
Large language models (LLMs) trained predominantly on English data encode substantial world knowledge, yet often fail to express it reliably in other languages, a phenomenon known as cross-lingual factual inconsistency. To study and address this, we introduce PolyFact, a large-scale parallel multilingual factual QA dataset containing 100K Wikidata-grounded facts across 12 typologically diverse languages. Using PolyFact, we compare light continual pretraining (CPT), supervised fine-tuning (SFT), and reinforcement learning via Group Relative Policy Optimization (GRPO) for improving cross-lingual factual recall in Qwen-2.5-7B and OLMo-2-1124-7B. We find that GRPO consistently outperforms SFT, improving both cross-lingual consistency and generalization to unseen languages, while CPT on parallel data yields limited additional gains. Mechanistic analyses further show that GRPO reorganizes multilingual routing by reducing language specialization in MLP layers and attention heads, thereby promoting more shared cross-lingual representations. We release our code, models, and dataset.

## 1. 核心问题与整体含义（研究动机和背景）

- **核心问题**：大型语言模型（LLMs）主要基于英语数据训练，编码了丰富的世界知识，但在非英语语言中难以可靠地表达这些知识，即**跨语言事实不一致性**。
- **背景**：已有研究表明，跨语言事实不一致通常不是由于知识缺失，而是发生在**语言转换阶段**——模型在中间层正确检索到答案，但在后续层无法可靠地映射到目标语言输出。现有方法如查询级干预（subject injection、英语中介）只是推理时的补丁，缺乏持久模型级改进。
- **意义**：探索如何在不进行大规模额外预训练的情况下，使模型通过非英语接口访问其已有的潜在知识，是提升多语言模型实用性和公平性的关键。

## 2. 方法论：核心思想、关键技术细节、公式或算法流程

### 2.1 核心思想
- 将**表示对齐**与**跨语言知识访问**分离。轻量持续预训练（CPT）主要负责表示对齐，而通过一致性驱动的强化学习（GRPO）直接优化跨语言事实回忆，促使模型形成更共享的跨语言表示。

### 2.2 关键技术细节

#### (a) 数据集 PolyFact
- 从Wikidata真实三元组中提取22种事实关系（地理、传记、创意作品、组织/文化关联），覆盖12种语言。
- 每个事实采样3个类型和长度匹配的干扰项，采用轮询均衡采样得到10万条事实。
- 用Gemma-3-27B-IT生成平行多项选择题（MCQ），通过GPT-4o网络搜索法官和人工审核进行质量评估，LLM-人类一致率91%。
- 数据分为95,000训练、2,500验证、2,500测试。

#### (b) 持续预训练（CPT）
- 在TED2025平行语料（12种语言）上进行轻量持续预训练，使用约512 token块打包，共325,134个块，总计2.355亿token。
- 对斯瓦希里语和孟加拉语额外补充平行句对。

#### (c) 基于GRPO的强化学习
- 采用多语言变体GRPO：每个训练样本是一个事实的平行12语言多项选择题，组大小为G=8，每次 rollout 包含12个独立生成（每种语言一个）。
- 奖励函数：
  ```
  R = Σℓ rℓ + ⊮[∀ℓ, rℓ = 1]
  rℓ = +1 (正确选项) | -0.5 (幻觉) | 0 (错误选项)
  ```
  正确回答所有语言额外+1奖励，鼓励跨语言一致性。

#### (d) 监督微调（SFT）
- 采用联合分类+一致性目标：
  ```
  L = -1/L Σℓ log pℓ(y*ℓ) + λ·1/L Σℓ KL(pℓ || sg(p̄))
  ```
  其中 p̄ 是12语言平均分布，sg表示停止梯度，λ=0.5。旨在模拟GRPO的联合奖励效应以公平比较。

### 2.3 机理分析技术
- **LAHIS**：基于一阶泰勒展开估计注意力头对语言处理的重要性，识别语言重要头。
- **LAPE**：基于MLP神经元激活频率的熵值识别语言特异性神经元。

## 6. 主要结论与发现

1. **GRPO显著优于SFT**：在所有评估场景中，GRPO提升跨语言事实回忆、向未见语言迁移、从多项选择泛化到自由形式生成的能力均超过SFT。
2. **CPT增益有限**：轻量持续预训练对平行数据本身提升流畅性，但未显著改善事实回忆，CPT+GRPO未产生叠加增益。
3. **机制差异**：
   - SFT主要增加**跨语言注意力头共享**，但语言路由结构基本不变。
   - GRPO**重新组织多语言路由**：减少早期层语言专用注意头，将语言处理推迟到更深层；增加英语特异性神经元，压缩其他语言神经元，但整体提升跨语言共享表示。
   - 层-rank分析显示GRPO改善了从知识表示到目标语言解码的过渡。
4. **迁移局限**：对拉丁字母或共享子词脚本的语言迁移较好，但对脚本孤立语言（如希腊语、韩语、希伯来语）提升有限，且存在一定的权衡（高资源语言微降）。

## 7. 优点

- **方法创新**：首次系统比较CPT、SFT和RL（GRPO）在跨语言事实回忆上的效果，明确区分了表示对齐与知识访问的分离观点。
- **数据集贡献**：PolyFact是首个大规模完全平行多语言事实QA数据集（10万事实×12语言），经过严格质量审核，开源支持可复现研究。
- **机理分析深入**：结合LAHIS和LAPE两种可解释性工具，从神经元和注意力头两个层面揭示GRPO如何重塑语言路由，为理解RL在多语言场景的作用提供实证。
- **实验设计严谨**：SFT使用一致性损失以隔离算法差异；评估覆盖多项选择、自由形式、泛化到未见语言；包含多种组合（CPT+后训练）。
- **实际意义**：证实跨语言事实不一致主要是“访问问题”而非“知识缺失”，一致性驱动RL提供了一种无需大规模预训练的高效解决方案。

## 8. 不足与局限

- **模型规模有限**：仅在两个7B模型上验证，无法保证推广到更大模型（如70B）或不同架构（MoE）。
- **泛化能力有限**：方法主要提升事实检索，在需要多步推理的Global-MMLU上改善幅度小，说明不是通用多语言推理解决方案。
- **数据集偏差**：PolyFact基于Wikidata，可能继承覆盖偏见、事实错误或实体标签偏差（如专有名词默认英语形式），导致特定类型问题（专有名词语义）上GRPO反而出现回归。
- **语言覆盖有限**：仅12种语言，且对脚本孤立语言（希腊语、韩语、希伯来语）迁移效果差，实际多语言应用可能面临更大挑战。
- **未完全揭示机制**：虽然发现GRPO增加英语特异性神经元，但为什么这能促进跨语言共享表示尚需进一步分析；奖励函数缺乏部分信用分配，可能未能充分利用不同语言错误模式的差异。
- **未报告详细算力消耗**：缺少GPU数量、训练时间等关键复现指标。
