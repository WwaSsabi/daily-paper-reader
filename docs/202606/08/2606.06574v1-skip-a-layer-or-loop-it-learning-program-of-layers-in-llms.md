## 摘要
大型语言模型（LLM）通过遵循固定的深度和顺序、非递归地执行所有层来进行推理。我们揭示了无训练、灵活、动态的层程序（PoLar）的广泛存在，其中预训练层可以作为模块打包，然后跳过或循环以形成针对每个输入的自定义程序。对于大多数输入，显著缩短的程序执行可以实现相同或更好的准确性，而原始LLM的错误预测可以通过层数更少的替代程序来纠正。这些观察表明，推理存在超出标准前向传播的多种有效潜在计算。为了在实践中高效实现PoLar，我们提出了一个轻量级的PoLar预测网络，它学习生成动态跳过或重复每个输入的预训练层的执行程序。在数学推理基准上的实验表明，PoLar在标准推理和先前的动态深度方法上持续提高了准确性，同时通常执行的层数更少，并且这些收益在分布外评估中仍然存在。我们的结果表明，固定深度执行只捕获了LLM潜在推理能力的一小部分。

## Abstract
Large language models (LLMs) perform inference by following a fixed depth and order, non-recurrent execution of all layers. We reveal the wide existence of training-free, flexible, dynamic program-of-layers (PoLar), where pretrained layers can be packed as modules and then skipped or looped to form a customized program for each input. For most inputs, substantially shorter program executions can achieve the same or better accuracy, while incorrect predictions of the original LLM can be corrected by alternative programs with fewer layers. These observations indicate that inference admits multiple valid latent computations beyond the standard forward pass. To efficiently achieve PoLar in practice, we propose a lightweight PoLar prediction network, which learns to generate execution programs that dynamically skip or repeat pretrained layers for each input. Experiments on mathematical reasoning benchmarks demonstrate that PoLar consistently improves accuracy over standard inference and prior dynamic-depth methods, often while executing fewer layers, and that these gains persist under out-of-distribution evaluation. Our results suggest that fixed-depth execution captures only a narrow subset of an LLM's latent reasoning capacity.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **研究动机**：当前大型语言模型（LLM）在推理时对所有输入都采用固定深度、固定顺序的前向传播（全部层依次执行）。然而，实际输入在难度和复杂度上差异巨大——简单问题可能只需较少计算，而困难问题可能需要更多推理步骤。这种“一刀切”的执行方式可能导致计算冗余或推理能力不足。
- **核心问题**：是否存在多种有效的“层执行程序”（即跳过或重复某些层）能在相同或更少计算下达到相同甚至更好的精度？能否学习一个轻量预测器，直接为每个输入生成最优执行程序，从而替代昂贵的测试时搜索？
- **整体含义**：论文通过蒙特卡洛树搜索（MCTS）发现标准前向传播只是众多有效执行路径中的一种；大多数输入存在更短的程序，而且联合使用跳过和循环操作能显著提升性能。这揭示了LLM的潜在推理能力远未被固定深度执行充分挖掘。基于此，作者提出 PoLar（Program-of-Layers）预测网络，将动态层执行从搜索问题转化为单次预测问题。

## 2. 论文提出的方法论：核心思想、关键技术细节

- **核心思想**：将预训练LLM的每一层视为一个固定函数（原子模块），推理过程被重新定义为根据输入动态调度这些函数（跳过或重复）形成的一个“程序”。每个程序由两部分表示：① 层的分割（segmentation）——将连续层划分为若干模块；② 每个模块的操作（skip / keep / repeat）。
- **关键技术细节**：
    1. **程序表示**：层分割用一个二值边界掩码 `z_seg ∈ {0,1}^D` 表示哪些位置是模块起点；操作用一个分类标签向量 `z_op ∈ {skip, keep, repeat}^D` 表示，仅在分割起点处有效。最大模块长度设为4（基于MCTS发现的结构偏置）。
    2. **PoLar预测网络**：对输入 x，先用冻结的嵌入模型（如 Qwen3-Embedding-0.6B）提取 token 表示；然后通过可学习的层查询嵌入与 token 表示的交叉注意力获得层相关的条件表示；再经过一个跨层 Transformer 编码器建模层间依赖；最后通过两个线性预测头输出分割边界 logits 和操作 logits。
    3. **训练**：使用 MCTS 离线收集的有效执行程序生成监督信号（分割和操作标签）。当存在多个有效程序且其中至少一个比完整模型更短时，降低完整深度程序的损失权重。训练目标为分割的二值交叉熵和操作的掩码交叉熵之和。
    4. **推理时解码**：先通过阈值确定分割边界（若超出最大长度则强制分割），然后在每个模块起始处计算操作概率，并使用小规模 beam search 选择全局一致的程序序列。每个候选程序按规则映射为实际层执行路径。

## 6. 论文的主要结论与发现

- **发现1**：联合使用跳过和循环操作比单独使用任一操作效果更好；循环操作在提效上比跳过更重要。
- **发现2**（奥卡姆剃刀）：大多数有效程序比标准前向传播更短，标准推理经常过度计算。
- **发现3**：增加潜在执行步骤（通过循环）系统地扩展有效程序空间，且困难任务更依赖循环和跳过操作；准确率随执行深度增加而单调提升。

## 7. 优点

- **无参数更新**：预测网络仅作用于冻结的预训练模型，不影响基座模型参数，易于部署。
