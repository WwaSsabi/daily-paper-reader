## 摘要
大型语言模型（LLM）在生成非英语文本时有时会出现语言混淆。现有方法通常依赖微调来缓解此问题。相比之下，我们提出了一种无需微调的范式来减少语言混淆。在此范式中，我们引入了两种方法：语言感知令牌提升（LATB），它对与目标语言相关的令牌应用有针对性的扰动；以及自适应语言感知令牌提升（Adaptive-LATB），它根据模型对预期语言的置信度动态调整这些扰动。实验表明，我们的方法通过减少语言混淆有效地改进了多语言对齐，同时在无需任何额外微调的情况下保持了摘要质量。我们的代码已公开。https://github.com/scbdatax/genai-datax-language-aware-token-boosting。

## Abstract
Large language models (LLMs) sometimes exhibit language confusion when generating non-English text. Existing approaches typically rely on fine-tuning to mitigate this issue. In contrast, we propose a tuning-free paradigm for reducing language confusion. Within this paradigm, we introduce two methods: Language-Aware Token Boosting (LATB), which applies targeted perturbations to tokens associated with the desired language, and Adaptive Language-Aware Token Boosting (Adaptive-LATB), which dynamically adjusts these perturbations based on the model's confidence in the intended language. Experiments demonstrate that our methods effectively improve multilingual alignment by reducing language confusion, while maintain the summarization quality without requiring any additional fine-tuning. Our code is publicly available. https://github.com/scbdatax/genai-datax-language-aware-token-boosting.

## 1. 核心问题与整体含义（研究动机和背景）

- **核心问题**：大型语言模型（LLM）在生成非英语文本时经常出现**语言混淆**（language confusion），即模型无法一致地生成目标语言，尤其在低资源语言场景下表现严重。这种混淆导致多语言任务质量下降。
- **现有方法局限**：现有的缓解手段包括降低温度、少样本提示和微调，但各有缺点：降低温度会减少响应多样性，微调需要额外计算成本且不够灵活。目前的主流范式是“参数调优对齐”（PTA）和“参数冻结对齐”（PFA），其中前者需要训练，后者依赖提示或检索增强。
- **整体含义**：本文首次提出一种**无需微调的日志扰动对齐范式**，通过直接修改推理时的logits来引导模型输出目标语言，以最小代价解决语言混淆问题。

## 2. 方法论：核心思想、关键技术细节、算法流程

### 核心思想
- 在LLM推理阶段，对**属于目标语言的令牌**对应的logits添加一个正扰动值α，增加这些令牌被采样的概率，从而减少语言混淆。
- 为了保留模型在高度自信时生成其他语言的能力，提出了**自适应版本**，仅当模型对目标语言与非目标语言的置信度差异低于阈值β时才施加扰动。

### 关键技术细节
1. **令牌语言识别**：基于Unicode过滤方法，判断令牌的所有字符是否属于目标语言的Unicode集合。同时纳入数字、特殊字符和句尾令牌。
2. **扰动向量构建**：定义一个扰动向量 **p**，对目标令牌索引 i ∈ I 赋予扰动值 α ≥ 0，其余为0。
   $$p_i = \begin{cases} \alpha & \text{if } i \in I \\ 0 & \text{otherwise} \end{cases}$$
3. **LATB（Vanilla LATB）**：
   - 将扰动向量加到原始logits上：`logits' = logits + p`
   - 然后通过Softmax得到新的概率分布。
4. **Adaptive LATB**：
   - 首先计算目标令牌的最大概率 `a = max({y_i | i ∈ I})` 和非目标令牌的最大概率 `b = max({y_i | i ∉ I})`。
   - 如果 `|a - b| < β`（表示模型对语言选择不自信），则施加扰动；否则保持原logits不变。
   - 超参数β控制触发扰动的敏感度（0 ≤ β ≤ 1）。

### 公式推导（重要性质）
论文证明：对于任意两个被提升的令牌 m, n ∈ I，扰动前后它们的概率比值保持不变：
$$\frac{y'_m}{y'_n} = \frac{y_m}{y_n}$$
说明扰动不改变目标令牌集合内部的相对排序，只整体提升它们的概率。

- LATB和Adaptive LATB均能**显著降低语言混淆**，在令牌级、行级、响应级指标上均大幅优于基础模型，甚至**超过微调模型Suzume**（例如泰语响应级混淆从2.30%降至0.00%）。

- 扰动不改变目标令牌内部概率比，保证了生成合理性和自然性。
- Adaptive LATB对超参数更鲁棒，能在需要时输出非目标语言（如英语技术术语），而Vanilla LATB在α过大时会强制“翻译”所有内容。

## 7. 优点

- **无需微调**：首次提出基于日志扰动的无调优对齐范式，部署成本极低，可即插即用于任何自回归LLM。
- **理论保证**：严格证明了扰动不改变目标令牌内部相对概率排序，保证了生成的合理性。
- **自适应机制**：Adaptive LATB能根据模型置信度智能切换是否施加扰动，避免强制单语言输出，增强灵活性。
- **实验全面**：多粒度语言混淆评估、多语言覆盖、与强基线（包括微调模型）对比、超参数分析及更强模型上的验证。
- **开源代码**：促进可复现性和实际应用。

## 8. 不足与局限

- **对未登录（OOV）令牌效果差**：方法依赖令牌在训练数据中的出现，对于LLM未学过或罕见的非英语令牌，提升效果有限。

- **超参数依赖**：虽然Adaptive LATB相对鲁棒，但α和β仍需针对具体模型和语言调优，增加了使用门槛。

- **计算开销**：Adaptive LATB存在非平凡的推理速度下降，对实时高吞吐场景可能不够友好。
- **缺少理论分析**：虽然给出了概率比不变证明，但未分析扰动对整体分布熵、多样性等的影响。
