## 摘要
微调数据选择需要平衡两个相互竞争的目标：选择能够改进下游目标的样本，同时避免重复微调模型。无训练选择器具有可扩展性，但依赖于嵌入相似性或聚类等代理指标，这些指标可能与目标目标不匹配。基于训练的选择器通过梯度信号、子集评估或Shapley归因更好地反映下游效用，但需要大量昂贵的训练-评估迭代。我们提出层级主动区域修剪（HARP），这是一种高效的基于训练的选择器，在保持下游对齐的同时降低选择成本。HARP将训练池组织成节点-叶子层级，仅评估代表性叶子节点，并使用经验贝叶斯后验推断未测量的效用。然后，它使用两种互补的包络线选择数据：HARP-C保守地控制冗余，HARP-E加法地奖励互补区域。我们在理论上证明，在局部平滑和有界估计误差下，HARP在控制选择误差的同时减少了训练-评估成本。我们进一步验证HARP变体取得了最佳结果，比最强基线高出最多+8.9个点，同时使用的训练样本大约减少了7倍。

## Abstract
Finetuning data selection requires balancing two competing goals: selecting examples that improve the downstream objective, and doing so without repeatedly finetuning models. Train-free selectors are scalable but rely on proxies such as embedding similarity or clustering, which may not match the target objective. Train-based selectors better reflect downstream utility through gradient signals, subset evaluation, or Shapley attribution, but require many costly train--evaluate iterations. We propose Hierarchical Active Region Pruning (HARP), an efficient train-based selector that preserves downstream alignment while reducing selection cost. HARP organizes the training pool into a node--leaf hierarchy, evaluates only representative leaves, and infers unmeasured utilities with empirical Bayes posteriors. It then selects data using two complementary envelopes: HARP-C, which conservatively controls redundancy, and HARP-E, which additively rewards complementary regions. We theoretically show that, under local smoothness and bounded estimation error, HARP controls selection error while reducing train--evaluate cost. We further validate that HARP variants achieve the best result and outperform the strongest baseline by up to $+8.9$ points, while using roughly $7\times$ fewer training examples.

## 1. 核心问题与整体含义（研究动机和背景）

大语言模型（LLM）微调需要从大量训练数据中挑选出高质量子集，以提升下游任务性能并降低计算成本。已有方法分为两类：**无训练方法**（如基于嵌入相似度、聚类或质量评分的数据选择）虽然计算高效，但其代理指标可能与实际下游目标（如准确率）不一致；**基于训练的方法**（如通过梯度信号、Shapley值或子集评估来估计样本贡献）虽能更好地对齐下游目标，但需要多次微调-评估迭代，成本过高。论文提出**HARP（Hierarchical Active Region Pruning）**，旨在在保持下游对齐的同时大幅降低训练-评估成本，实现高效的数据选择。

## 2. 方法论：核心思想、关键技术细节

### 核心思想
HARP通过将训练数据集组织成**节点-叶子层级结构**，仅评估少量代表性叶子节点的下游效用，然后利用**经验贝叶斯（Empirical Bayes）** 后验推断未测量叶子的效用，并设计两种互补的包络线（envelope）来优化选择。

### 关键技术细节
1. **代理评估集构建**：将完整评估集划分为领域（domain），在每个领域内通过k-means++采样少量代表性样本构成代理评估集，用于降低每次评估成本。
2. **层级节点-叶子构建**：基于训练样本的嵌入，使用最远优先（farthest-first）策略将训练数据递归划分为节点和叶子。每个叶子包含一组样本（大小介于256~1024之间），作为选择的基本单元，从而减少需要评估的候选单元数量。
3. **主效应估计**：
   - 在每个节点内选择少量代表性叶子（默认每个节点3个），在其上微调模型并在代理评估集上评估，得到原始的效用测量。
   - 对于未测量的叶子，使用余弦相似度加权插值（cosine-similarity kernel）从同节点代表叶子估计其效用。
   - 进一步应用经验贝叶斯收缩（EB shrinkage），将局部插值估计向全局均值收缩，得到最终的主效应估计$\hat{\phi}_g(d)$。
4. **选择包络线**：
   - **HARP-C（保守覆盖包络）**：对每个领域，仅取最大正效应，累加所有负效应，以避免冗余带来的高估。使用贪婪边际增益选择叶子，最终取最佳可行前缀。
   - **HARP-E（扩展加法包络）**：对每个领域，将所有叶子效应简单相加（正负抵消），以允许多个互补叶子在同一领域内共同贡献。同样使用贪婪选择。
5. **理论保证**：论文证明了在局部平滑性和有界估计误差下，HARP能控制选择误差，且HARP-C和HARP-E具有不同敏感度界限（$(K+1)\eta$ vs $K\eta$）。

## 6. 主要结论与发现

- HARP变体（HARP-C和HARP-E）在36组实验中取得**28组最佳（78%）**，平均准确率61.4（HARP-C）和60.4（HARP-E），远超最强基线SHED-O（52.5）和Full FT（45.7）。

- **互补性**：HARP-C在噪声较大的SI和异质Tulu上表现更好；HARP-E在干净、任务相关的Wiz上最佳。
