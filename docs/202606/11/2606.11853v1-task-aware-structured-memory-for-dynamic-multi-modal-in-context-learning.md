## 摘要
多模态大语言模型（MLLMs）依赖上下文学习（ICL）实现快速任务适应，但其可扩展性受限于有限的上下文窗口以及长多模态序列中键值（KV）缓存不断增长的成本。现有记忆压缩方法通常依赖僵化的令牌移除或样本依赖的重要性估计，这会引入偏差，破坏语义结构（尤其是视觉表示），并产生无法适应新查询的静态记忆。我们提出TASM（任务感知结构化记忆），这是一种无需训练框架，通过任务感知、结构保持和动态可访问的记忆构建来解决这些局限。TASM采用任务向量引导的压缩，用捕获演示间共享相关性的任务级方向替代样本特定信号。为保持底层流形，它通过二分图匹配实现语义感知的令牌合并，在不进行破坏性修剪的情况下聚合令牌。最后，TASM将记忆组织为包含紧凑核心记忆和潜性库的层次结构，便于查询自适应的动态检索。评估证实TASM在高压缩下保持高性能，有效平衡了效率与适应性。

## Abstract
Multi-modal large language models (MLLMs) depend on in-context learning (ICL) for rapid task adaptation, but their scalability is severely limited by finite context windows and the growing cost of key-value (KV) caches in long multi-modal sequences. Existing memory compression approaches typically rely on rigid token removal or sample-dependent importance estimation, which introduces bias, disrupts semantic structure, particularly for visual representations, and yields static memories that cannot adapt to new queries. We introduce TASM (Task-Aware Structured Memory), a training-free framework that addresses these limitations through task-aware, structure-preserving, and dynamically accessible memory construction. TASM employs task-vector guided compression to replace sample-specific signals with a task-level direction that captures shared relevance across demonstrations. To preserve the underlying manifold, it applies semantics-aware token merging via bipartite graph matching, aggregating tokens without destructive pruning. Finally, TASM structures memory into a hierarchy comprising a compact Core Memory and a Latent Bank, facilitating query-adaptive dynamic retrieval. Evaluations confirm TASM maintains high performance under heavy compression, effectively balancing efficiency with adaptability.

## 2. 论文提出的方法论

### 核心思想
TASM将记忆压缩从特定演示样本解耦，将KV缓存视为任务的**结构化表示**，而非静态缓冲区。通过**任务向量**引导压缩，保留语义拓扑，并引入层次化记忆实现查询自适应动态检索。

### 关键技术细节

#### 2.1 任务向量引导的重要性估计
- 从少量问答演示中提取**任务向量** \(\tau_l\)：计算问题和答案在激活空间中的质心，取归一化差值作为任务方向。  
- **正交投影评分**：将每个令牌的键表示投影到任务向量上，结合键范数，计算任务重要性分数 \(s_{i,l}^{\text{task}}\)。  
- **分层自适应门控**：对浅层和深层Transformer层使用不同权重 \(\lambda(l)\)（浅层偏向注意力分数，深层偏向任务向量分数），形成分层重要性度量。

#### 2.2 语义感知的令牌合并
- 将令牌分为**源节点**（低分令牌）和**汇节点**（高分令牌），构建二分图，通过匹配寻找最优分配，最大化保留语义信息。  
- **空间约束**：对视觉令牌强制局部窗口约束（\(\Delta_{\text{win}}=3\)），防止物理距离远的补丁合并，保持2D特征几何。  
- **流形保持聚合**：源令牌通过加权质心更新汇令牌，实现信息压缩而非丢弃。

#### 2.3 信息几何动态检索
- 构建层次记忆：**核心记忆**（GPU驻留，紧凑）和**潜性库**（CPU卸载，大容量）。  
- 使用**Jensen-Shannon散度**检测注意力分布变化，当 \(D_{\text{JS}} > \epsilon\) 时触发检索，从潜性库中获取最相关历史令牌，动态扩展有效缓存。

### 算法流程（文字说明）
1. 从支持集 \(\mathcal{S}_{\text{few}}\) 提取任务向量 \(\tau\)（仅一次）。  
2. 预填充阶段：对输入序列进行分层重要性评分，基于任务向量和自适应门控。  
3. 语义感知合并：根据重要性将令牌分为源和汇，构造二分图，在空间约束下进行加权聚合，压缩为核心记忆（20%）和潜性库（40%）。  
4. 推理阶段：对于每个新生成步骤，计算当前注意力分布与参考分布的JS散度；若超过阈值，从潜性库检索Top-k令牌加入当前缓存。  
5. 解码：对扩展后的缓存进行标准多头注意力。

## 7. 优点
1. **无需训练**：完全基于推理阶段的操作，无需微调或额外参数更新，适应性强。  
2. **结构保留**：用软合并替代硬剪枝，保留2D视觉流形，提升空间定位能力。  
3. **动态自适应**：通过JS散度驱动检索，只在必要时扩展上下文，避免静态记忆的信息丢失。  
4. **任务意识**：任务向量捕获全局推理方向，有效过滤样本级噪声和注意力下沉。  
5. **广泛的泛化性**：在多种MLLM架构（Qwen2-VL、LLaVA-NeXT、InternVL3）上均表现稳定，且任务向量可跨类迁移。  
6. **高效性**：在极低内存预算（比如10-20%保留率）下仍保持高性能，解码速度接近EMLoC，远快于全上下文。

## 8. 不足与局限
- **计算开销**：与纯硬剪枝方法相比，TASM在预填充阶段引入了二分图匹配和任务向量提取的额外延迟（约+35ms/32k token），虽小但存在。  
- **超参数敏感**：任务向量插值权重 \(\alpha\)、JS阈值 \(\delta\)、空间窗口 \(\Delta_{\text{win}}\) 等需要手动调节，论文虽提供推荐值但未给出自动化方案。  
- **极长上下文扩展**：论文实验最大约32k tokens（A800 80GB），未测试超长序列（100k+）下的表现。尽管动态检索有潜力，但潜性库膨胀和CPU-GPU传输可能成为新瓶颈。  
- **单次任务向量提取**：任务向量仅由支持集一次提取，若任务分布发生剧烈变化（如从分类切换到计数），需要重新提取，未讨论增量更新机制。  
- **应用限制**：目前仅评估了视觉-语言任务，未涵盖纯文本或音频等更多模态。此外，动态检索的时机基于注意力分布，可能对某些生成提前终止不敏感。  
- **潜在偏差**：虽然任务向量减少了样本偏差，但支持集本身可能仍存在任务定义偏差（例如仅少数示例不能覆盖完整分布），在低样本设置下（N=1）性能下降较大。
