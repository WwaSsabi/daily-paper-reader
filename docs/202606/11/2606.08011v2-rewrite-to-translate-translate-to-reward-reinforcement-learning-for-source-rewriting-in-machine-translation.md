## 摘要
在翻译之前使用大型语言模型（LLM）重写源文本已被证明可以提高机器翻译（MT）质量。然而，我们发现基于提示的重写可能会降低而不是提高翻译质量，特别是当使用较小的LLM（例如4B参数模型）时。我们认为，这种局限性源于仅通过自然语言提示难以控制重写行为：只有当重写能改善下游翻译时才有用，但现有的基于提示的方法并未明确优化这一信号。为了解决这个问题，我们提出了RLSR（源重写的强化学习），这是一种强化学习框架，它根据每次重写产生的下游翻译质量改进来奖励训练重写模型。在六个MT系统和16个语言对上的实验表明，我们的4B参数RLSR训练的重写模型在相同模型规模下显著优于无重写基线和基于提示的重写基线，同时与使用235B LLM的基线保持竞争力。

## Abstract
Rewriting source text with large language models (LLMs) before translation has been shown to improve machine translation (MT) quality. However, we find that prompt-based rewriting can degrade translation quality rather than improve it, particularly when smaller LLMs, such as 4B-parameter models, are used. We argue that this limitation stems from the difficulty of controlling rewriting behavior through natural-language prompts alone: a rewrite is useful only if it improves downstream translation, yet existing prompt-based methods do not explicitly optimize for this signal. To address this issue, we propose RLSR (Reinforcement Learning for Source Rewriting), a reinforcement learning framework that trains the rewriting model with a reward based on the downstream translation-quality improvement produced by each rewrite. Experiments across six MT systems and 16 language pairs show that our 4B RLSR-trained rewriting models significantly outperform both the no-rewriting baseline and prompt-based rewriting baselines at the same model scale, while remaining competitive with baselines that use a 235B LLM.

# 论文总结：Rewrite to Translate, Translate to Reward: Reinforcement Learning for Source Rewriting in Machine Translation

## 1. 核心问题与整体含义（研究动机和背景）

- **背景**：在机器翻译（MT）前，使用大语言模型（LLM）对源文本进行重写（source rewriting）已被证明能提升翻译质量。常见方法是通过自然语言提示（如“简化”、“释义”、“便于翻译”）引导LLM重写。
- **核心问题**：基于提示的重写在小模型（如4B参数）上不可靠，常常反而降低翻译质量。原因是提示仅能间接控制重写行为，而重写的实际价值取决于它是否真正改善了下游翻译；现有方法并未显式优化这一信号。
- **研究目标**：探索一种能直接优化下游翻译质量提升的源重写方法，使重写模型（即使是小模型）稳定且有效地改善翻译效果。

## 2. 方法论

### 核心思想
- 使用**强化学习（RL）** 训练一个源重写模型，将**下游翻译质量的提升**作为奖励信号，从而直接优化重写行为，取代依赖提示的间接控制。

### 关键技术细节
- **形式化定义**：
  - 令 \(s\) 为源文本，\(r\) 为参考译文，\(M\) 为固定MT模型，\(R_\theta\) 为参数为 \(\theta\) 的重写模型。
  - 重写模型生成改写文本 \(\tilde{s} = R_\theta(s)\)，MT模型分别翻译原文本 \(M(s)\) 和改写文本 \(M(\tilde{s})\)。
  - 奖励 \(R(s, \tilde{s}, r) = Q(s, M(\tilde{s}), r) - Q(s, M(s), r)\)，其中 \(Q\) 为自动评估指标（本文使用 xCOMET-XL）。
- **RL目标**：
  - 最大化期望调整奖励 \(J(\theta) = \mathbb{E}_{s \sim D, \tilde{s} \sim R_\theta(\cdot|s)}\left[ R(s,\tilde{s},r) - \beta \log \frac{R_\theta(\tilde{s}|s)}{R_{\text{ref}}(\tilde{s}|s)} \right]\)，其中KL惩罚项防止奖励黑客攻击（生成无意义文本）。
- **优化算法**：采用 **DAPO**（Decoupled Clip and Dynamic Sampling Policy Optimization），一种基于策略梯度的on-policy RL算法。
- **初始策略**：使用基于“Easy Translate”提示的指令遵循LLM作为参考策略 \(R_{\text{ref}}\)。

### 算法流程（文字说明）
1. 从训练数据集采样一条源文本 \(s\) 及其参考译文 \(r\)；
2. 当前重写策略 \(R_\theta\) 生成一个改写文本 \(\tilde{s}\)；
3. 固定MT模型 \(M\) 翻译 \(s\) 和 \(\tilde{s}\)，得到两个译文；
4. 用自动指标 \(Q\) 分别评估两个译文，计算奖励 \(R\)；
5. 加入KL散度惩罚得到总奖励 \(R_{\text{total}}\)；
6. 利用DAPO算法更新策略 \(R_\theta\)，最大化期望总奖励；
7. 重复以上步骤直至收敛。

## 6. 主要结论与发现

1. **提示重写在小模型上不可靠**：所有6个MT模型上，4B Qwen3提示重写基线均未优于无重写基线，甚至经常更差。
2. **RLSR显著有效**：4B RLSR重写模型在大多数设置下显著优于无重写基线和同规模提示基线，且与235B提示基线性能相当。
3. **RL优于SFT**：SFT训练的重写模型倾向于复制源文本（复制率高达75-90%），而RL训练模型仅复制6-8%，且翻译质量显著更高。DPO介于中间但不如RL稳定。
4. **跨MT泛化能力**：RLSR训练的重写模型可以交叉应用于另一个MT模型，性能损失很小；联合训练单一模型也能同时服务多个MT模型。表明重写策略主要针对通用翻译障碍而非模型特有偏好。
5. **RLSR学习局部、长度保持的编辑**：RLSR重写保留高源相似度（0.69-0.85），仅修改妨碍翻译的片段（如口语化表达、歧义、非字面表达），而非像提示方法那样大规模改写。
6. **案例分析**：RLSR能识别并修正翻译障碍（如未翻译的“whatever”、歧义的“area”），而提示方法会引入虚构内容或错误的概念。

## 7. 优点

- **直接优化目标**：将翻译质量提升直接作为奖励，克服了提示方法间接、不可靠的缺陷。
- **有效控制小模型**：4B模型也能通过RL学习高效的重写策略，达到大模型（235B）的效果，降低计算成本。
- **鲁棒性与泛化性**：在多个MT模型和语言对上一致提升；跨MT泛化分析表明方法具有通用性。
- **避免退化**：RL框架避免了SFT中的复制退化，生成多样化且有意义的改写。
- **分析深入**：通过源相似度、复制率、案例分析等全面解释RL成功的原因，并与SFT、DPO做了系统对比。

## 8. 不足与局限

- **度量偏差风险**：训练时使用xCOMET作为奖励，可能导致RLSR偏向该指标；虽用GEMBA验证，但缺乏人工评估。
- **计算成本高**：RLSR训练需要约60 GPU-hours，且需要反复运行MT模型和评估指标，比SFT昂贵；对每个新MT模型原则上需单独训练，增加部署成本。
- **实验范围有限**：
  - 仅验证了Qwen3 4B作为重写模型架构（Gemma4探索中提示基线无改善，未继续RL训练）；
  - 跨MT泛化实验仅涉及2个MT模型，扩展到更多模型需进一步验证；
  - 未在更广泛的领域（如对话、文学）及更多语言对上测试。
- **缺乏人工评估**：尽管使用了多个自动指标，但最终翻译质量的最佳验证仍需人工评价。
- **RL训练稳定性依赖超参数**：KL系数、采样数量等需要调优，文中仅给出单一设置。
- **方法依赖固定MT模型**：重写模型是针对特定MT模型训练的，更换MT模型时需要额外训练或验证泛化性。
