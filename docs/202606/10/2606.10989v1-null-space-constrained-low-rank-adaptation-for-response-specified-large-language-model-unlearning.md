## 摘要
大型语言模型遗忘旨在抑制指定的不良知识，同时保留良性能力。许多遗忘目标侧重于抑制不良回答，而最近的目标引导变体则指定替代行为，但依然在很大程度上未对更新局部性进行约束。本文提出了零空间约束的响应指定遗忘（NSRU），这是一种用于受控LLM遗忘的投影约束低秩框架。NSRU使用显式结构化的安全目标响应来指定每个遗忘查询的期望行为，同时抑制原始不良内容。为了定位适应，NSRU从良性隐藏表示中估计每模块的保留子空间，并使用正交投影的低秩参数化将LoRA更新约束到保留子空间的零空间中。由此产生的目标在此约束参数化下联合优化安全目标学习、不良响应抑制和保留保持。我们提供了一个局部一阶分析，表明投影更新减少了保留侧的扰动，同时保留了用于塑造遗忘查询行为的可编辑方向。在TOFU上的实验表明，NSRU在抑制可提取的遗忘集知识的同时，相比代表性基线提高了保留QA性能、模型效用和安全目标对齐。在WMDP上，NSRU将危险领域准确率保持在接近随机选择的区域，同时保留了广泛和领域邻近的MMLU效用。消融研究支持了安全目标监督、不良响应抑制、保留损失和零空间投影更新的互补作用，而敏感性和鲁棒性分析表明在所测试的超参数和提示变化下行为稳定。

## Abstract
Large language model unlearning aims to suppress designated undesirable knowledge while preserving benign capabilities. Many unlearning objectives focus on suppressing undesired answers, while recent target-guided variants specify replacement behavior but still leave update locality largely unconstrained. This paper introduces \emph{Null-Space Constrained Response-Specified Unlearning} (NSRU), a projection-constrained low-rank framework for controlled LLM unlearning. NSRU uses an explicitly structured safe target response to specify the desired behavior for each forget query, while suppressing the original undesired content. To localize adaptation, NSRU estimates per-module retain subspaces from benign hidden representations and uses an orthogonal-projected low-rank parameterization to confine LoRA updates to the null space of the retain subspace. The resulting objective jointly optimizes safe-target learning, undesired-response suppression, and retention preservation under this constrained parameterization. We provide a local first-order analysis showing that the projected update reduces retain-side perturbations while preserving editable directions for shaping forget-query behavior. Experiments on TOFU show that NSRU effectively suppresses extractable forget-set knowledge while improving retain QA performance, model utility, and safe-target alignment over representative baselines. On WMDP, NSRU keeps hazardous-domain accuracy near the random-choice region while preserving broad and domain-adjacent MMLU utility. Ablation studies support the complementary roles of safe-target supervision, undesired-response suppression, retention loss, and null-space projected updates, while sensitivity and robustness analyses indicate stable behavior across the tested hyperparameter and prompt variations.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **研究动机**：大型语言模型（LLM）广泛应用于需要避免生成受限或不良知识的场景（如敏感个人信息、危险指令、版权内容）。LLM 遗忘旨在减少指定遗忘数据的影响，同时保留模型在良性输入上的行为。
- **现有方法的不足**：许多方法仅抑制不良回答（如梯度上升），但未指定遗忘后的替代行为；即使有目标引导的变体指定替换响应，仍缺乏对更新局部性（update locality）的约束——遗忘和保留行为共享模型表征，改变前者可能无意中损害后者。
- **核心挑战**：需要同时解决两个问题：① 响应控制：不仅抑制不良回答，还要指定一个安全、连贯的替代响应；② 更新局部性：保护与保留行为相关的参数方向，使更新只作用于可编辑的剩余方向。
- **本文意义**：提出一种约束适应视角，将响应指定遗忘形式化为一个受约束的优化问题，通过显式结构化的安全目标响应和保留子空间零空间投影，实现可控的局部更新。

## 2. 论文提出的方法论：核心思想、关键技术细节

- **核心思想**：将响应指定遗忘建模为受约束的低秩适应问题，利用保留子空间的零空间约束 LoRA 更新，联合优化安全目标学习、不良响应抑制和保留保持。
- **关键技术细节**：
  - **响应指定设定**：每个遗忘样本 \((x_i, y_i^-, y_i^+)\)，其中 \(y_i^-\) 是原始不良响应，\(y_i^+\) 是离线构造的安全目标响应（由安全提示引导的外部 LLM 生成，包含安全理由前缀 \(r_i^+\) 和最终安全答案 \(a_i^+\)）。
  - **保留子空间估计**：从保留集隐藏表征中，对每个选中的可训练模块 \(l\)，使用无中心秩截断 SVD 提取前 \(k_l\) 个奇异方向（能量阈值 \(\rho=0.9\)），构成正交基 \(U_l\)，定义保留投影器 \(P_l=U_lU_l^\top\) 和零空间投影器 \(P_l^\perp = I - P_l\)。
  - **零空间约束的低秩适应**：标准 LoRA 更新 \(\Delta W_l h_l\) 被替换为 \(\frac{\alpha_l}{r_l} B_l A_l P_l^\perp h_l\)，即 LoRA 只作用于零空间分量 \(P_l^\perp h_l\)。反向传播时，梯度也自动只包含零空间成分，无需额外投影步骤。
  - **训练目标**：联合损失 \(L = L_{\text{safe}} + \lambda_f L_{\text{undesired}} + \lambda_r L_{\text{ret}}\)：
    - \(L_{\text{safe}} = \mathbb{E}_{D_f} \bar{\ell}_{\theta'}(y^+|x)\)（学习安全目标）
    - \(L_{\text{undesired}} = -\mathbb{E}_{D_f} \bar{\ell}_{\theta'}(y^-|x)\)（抑制不良回答）
    - \(L_{\text{ret}} = \mathbb{E}_{D_r} \bar{\ell}_{\theta'}(y|x)\)（保持保留集行为）
  - **算法流程**（算法 1）：① 从保留集采样估计子空间并固定投影器；② 冻结主干参数，仅训练低秩因子 \(\{A_l, B_l\}\)；③ 迭代优化联合损失。
- **理论分析**：局部一阶分析表明，对于保留输入，零空间能量小，投影更新对保留侧影响有限；对于遗忘输入，若含有非零零空间能量，局部仍可编辑。

## 6. 论文的主要结论与发现

- **TOFU 上**：NSRU 实现零提取强度（ES=0），显著提升保留 QA 性能（R-ROUGE 达 0.96+）、模型效用（MU 达 0.68+）和安全目标对齐（ST-ROUGE 达 0.48+），远优于所有基线（包括 TRU）。
- **WMDP 上**：NSRU 将危险领域准确率维持在接近随机水平（≈27%），同时保留 MMLU 整体准确率（≈0.57，接近未遗忘模型）和领域邻近 MMLU，优于其他基线（后者往往严重降低效用）。
- **消融结论**：安全目标损失、不良抑制损失、保留损失和零空间投影均不可或缺，缺失任一都会导致某一指标严重下降（如无不良抑制时 ES 剧升至 0.83）。

- **鲁棒性**：在 ReLU 格式变换下，NSRU 保持最低遗忘恢复和最高保留转换能力；在跨语言和越狱提示下，WMDP 准确率仍接近随机水平，未发生显著恢复。
