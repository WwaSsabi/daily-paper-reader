## 摘要
训练后量化（PTQ）对于大语言模型（LLM）的高效部署至关重要。最近的超低位PTQ方法依赖于严格的权重显著性假设或位置启发式，引入了大量的隐藏缩放开销。我们提出SAGE-PTQ（显著性感知的图引导高效PTQ），一种新颖的LLM超低位量化框架，可最小化隐藏缩放成本。SAGE-PTQ使用分布统计分离显著与非显著权重，然后将子采样后的非显著权重建模为稀疏图，以估计每层的最优组数。SAGE-PTQ应用双模量化，对显著权重分配多比特精度，对非显著权重进行二值化。为降低缩放开销，SAGE-PTQ对显著权重使用每通道一个缩放因子，对每个非显著组使用一个标量。最后，SAGE-PTQ实施自适应显著性阈值，为每个矩阵选择最优显著性比率。SAGE-PTQ平均每个矩阵达到1.03权重比特和仅0.004缩放比特，优于BiLLM和PB-LLM等最新方法。在LLaMA-3-8B上，SAGE-PTQ达到6.74的WikiText2困惑度，而BiLLM为55.8，同时使用的GPU内存不到BiLLM的50%。在LLaMA-2-70B上，SAGE-PTQ在一张NVIDIA L40 GPU上提供1.5倍的解码加速，展示了实际的推理效率。

## Abstract
Post-training quantization (PTQ) is critical for the efficient deployment of large language models (LLMs). Recent ultra-low-bit PTQ methods rely on rigid weight-saliency assumptions or position heuristics, introducing substantial hidden scaling overhead. We propose SAGE-PTQ (Saliency-Aware Graph-guided Efficient PTQ), a novel ultra-low-bit quantization framework for LLMs that minimizes hidden scaling cost. SAGE-PTQ separates salient and unsalient weights using distributional statistics, then models subsampled unsalient weights as a sparse graph to estimate the optimal number of groups per layer. SAGE-PTQ applies dual-mode quantization, assigning multi-bit precision to salient weights and binarizing unsalient weights. To reduce scaling overhead, SAGE-PTQ uses one per-channel scale for salient weights and one scalar per unsalient group. Finally, SAGE-PTQ implements adaptive saliency thresholding to select the optimal saliency ratio per matrix. SAGE-PTQ achieves 1.03 weight bits and only 0.004 scaling bits per matrix on average, outperforming state-of-the-art methods such as BiLLM and PB-LLM. On LLaMA-3-8B, SAGE-PTQ achieves 6.74 WikiText2 perplexity, compared to 55.8 for BiLLM, while using less than 50% of BiLLM's GPU memory. On LLaMA-2-70B, SAGE-PTQ provides 1.5x faster decoding on one NVIDIA L40 GPU, demonstrating practical inference efficiency.

## 1. 核心问题与整体含义（研究动机和背景）
- **问题**：大规模语言模型（LLM）因参数量巨大，部署时面临严重的内存和延迟瓶颈。后训练量化（PTQ）是有效压缩手段，但现有超低位（sub-2-bit）PTQ方法（如BiLLM、PB-LLM）依赖刚性的权重显著性假设或位置启发式（如固定分块），导致**隐藏的缩放（scale）开销**可超过1比特/权重，抵消二值化带来的收益。
- **动机**：现有方法在**显著性处理**（阈值固定）、**权重划分**（忽略分布异质性）、**量化策略**（简单min-max缩放造成大误差）和**查找效率**（运行时开销大）等方面存在核心缺陷。SAGE-PTQ旨在全面最小化缩放成本，实现高效的超低位量化。
- **整体含义**：提出一个通用、模型无关的量化框架，通过图引导的组估计和自适应显著性阈值，在极低比特下（平均1.03权重比特/0.004缩放比特）显著优于现有方法，并实际部署中实现内存减半和1.5倍加速。

## 2. 方法论
### 核心思想
- 利用权重分布统计分离**显著（salient）权重**（需要高精度）和**非显著（unsalient）权重**（可二值化）。
- 对非显著权重建模为**稀疏K近邻图**，通过谱聚类和轮廓系数（Silhouette Score）估计每层最优分组数，避免固定分块。
- 采用**双模量化**：显著权重使用多比特量化（每通道一个缩放因子），非显著每组使用**单个标量**的二值量化，极度缩减少缩放存储。
- 设计**自适应显著性阈值**优化目标，对每个矩阵最小化归一化重构误差，选择最优显著性比例。

### 关键技术细节
- **显著权重过滤**：基于均值+标准差+probit函数自适应选择阈值，仅保留绝对值超出分布尾部的大权重（通常<10%）。
- **图引导组数估计**：对非显著权重子采样构建稀疏KNN图，用谱聚类评估候选组数（受查找表位宽约束），通过轮廓分数选择最优组数。
- **双模量化**：
  - 模式1（显著）：交替优化缩放向量和离散化矩阵，最终映射到均匀量化级。
  - 模式2（非显著）：每组使用三元矩阵{−1,0,1}和单标量缩放，通过闭合形式求解最优标量。
- **自适应阈值**：使用Brent方法优化每个矩阵的显著性百分位，在重构误差和存储约束间平衡。
- **高效推理**：使用位打包的查找表（LUT）编码组索引，离线存储于主机内存，层加载时解码，引入极小开销。
